# SmartClass

React + Vite + Tailwind app, ready for Vercel.

## Local dev

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

- Import this repo/project in Vercel.
- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
